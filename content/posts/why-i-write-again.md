停更两年之后，我又把博客重新搭了起来。

不是因为突然有了很多想说的，而是发现有些想法如果不写下来，过一阵就再也想不起来了。写下来，至少留下了一点痕迹。

## 为什么又开始写

换了几个写作工具，最后发现最顺手的还是最普通的文本文件。本地写，提交，网站自动构建。没有后台，没有数据库，也不用记得密码。

> 写作不是为了被看见，而是为了把飘着的念头按在纸上。

这句话是朋友说的，我记了很久。

## 我打算写什么

- 日常里的小事
- 读过、看过的东西
- 偶尔的技术笔记

这里不会追热点，也尽量不写自己没想明白的东西。如果你对作者感兴趣，可以去[关于我](/about/)看看；也可以从[上一篇读书笔记](/posts/reading-kamakura-stationery/)读起。

给自己定了三条小规则：

1. 每周至少写一次，长短不限。
2. 写完放一天再改，别急着发。
3. 不为了更新而写。

## 写作之外的小事

### 一些工具

现在用本地 Markdown 写稿，提交后由网站自动构建。文章模板长这样：

```js
const post = {
  title: '文章标题',
  slug: 'article-slug',
  date: '2026-11-11',
  tags: ['随笔'],
};
```

| 编辑器 | 写稿 | 是 |
| 终端 | 预览与构建 | 是 |
| 笔记本 | 记零散的想法 | 偶尔 |
